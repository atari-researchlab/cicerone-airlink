Alarma.h File Reference

Cabecera para la gestión de alarmas temporizadas y promedio de datos. More...

Detailed Description

Declara las funciones y variables globales para controlar tareas periódicas (ej. cada 5s, cada 10min) y para manejar los datos de los sensores.
