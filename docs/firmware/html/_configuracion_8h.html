◆ HABILITAR_NBIOT

Comenta o descomenta estas líneas para incluir o excluir funcionalidades del programa final. Esto es útil para ahorrar memoria y potencia si no se usan todos los módulos.

◆ APN_NBIOT

#define APN_NBIOT   "iot.1nce.net"

Introducir el APN del proveedor de internet. Hay proveedores para los que no es necesario introducir el APN. Ejemplos:

#define APN_NBIOT "" // Sin APN
#define APN_NBIOT "iot.1nce.net" // APN de 1NCE
#define APN_NBIOT "TM" // APN de ThingMobile
