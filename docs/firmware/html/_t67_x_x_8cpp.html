Esta es una biblioteca para el módulo sensor de CO2 miniatura de la serie Telaire T67XX. More...

Detailed Description

Estos sensores utilizan UART e I2C para comunicarse. Esta biblioteca está diseñada para la opción de comunicación I2C. Se requieren 2 pines para la interfaz. Para habilitar la comunicación I2C, conecte el pin CTRL (pin 6 del módulo) a GND.
