Configuración de los mensajes de depuración.

Controla la cantidad de información de cada módulo que se imprime en el Monitor Serie cada módulo y de forma global. Si el nivel de depuración es 0, todas las macros de depuración se definen como vacías. El compilador las optimizará y las eliminará del código final, ahorrando memoria.

  • 0 = Sin depuración. Ahorra memoria y hace el programa más rápido.
  • 1 = Errores (ERROR): Muestra solo mensajes críticos.
  • 2 = Advertencias (WARN): Muestra errores y advertencias importantes.
  • 3 = Información (INFO): Muestra el flujo general del programa (recomendado para depuración normal).
  • 4 = Detallado (VERBOSE): Muestra información muy detallada, como lecturas de sensores cada 5s.

Macros de depuración.

Se utilizan al igual que la función printf(). Agregan automaticamente el nivel de DEBUG, los millis actuales a modo de timestamp y el módulo que lo generó.

Ejemplo:

DEBUG_ERROR("No es posible establecer la comunicación con el RTC");
